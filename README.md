# SQL Student Database

A small practice database with three tables (students, courses, enrollments) and 13 SQL queries.
The sample data is fictional.

## What's inside
| File | Purpose |
|------|---------|
| `schema.sql` | Creates the tables, primary keys, foreign keys and constraints |
| `sample_data.sql` | Fictional students, courses and grades |
| `queries.sql` | 13 queries: filtering, joins, grouping, subqueries, and data-quality checks |

## Skills practised
- `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
- `JOIN` and `LEFT JOIN`
- `GROUP BY` with `COUNT`, `AVG`, `HAVING`
- `CASE` expressions and subqueries
- Data-quality checks used in testing (invalid values, orphan records, duplicates)

## How to run it
1. Open an SQLite tool (for example DB Browser for SQLite, or an online SQLite editor).
2. Run `schema.sql`, then `sample_data.sql`.
3. Run the queries in `queries.sql` one at a time.
